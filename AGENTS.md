# Project commands

- Run tests: `python -m pytest`
- Run the editor: `$env:PYTHONPATH='src'; python -m arcana_editor`
- Extract maps: `$env:PYTHONPATH='src'; python -m arcana_editor.extract "Arcana (USA).sfc" extracted`
- Build Windows executable: `.\build.ps1`
- Never commit ROM files, extracted game assets, generated projects, or build output.
